1 · Gravity frame

The documented failure where a policy freezes in a split stance is an out-of-distribution observation: the net was trained with gravity on one axis and is being fed another. Instead of demanding the policy match the phone, this measures how the phone is actually mounted and rotates the observation into whatever frame the policy declares.

Support the body off the ground and power the MG90S servos from the servo board supply. Never power six servos from the Pico USB rail. Test one channel at a time before walking.

Slow mind

The gait is the fast brain. This is the slow one: it looks through the camera, reads the body's own sense of itself, and decides what the creature should do next — then calls the same motion tools you have been using by hand.

Community build uses the selected cloud vision model.

The selected Brain model is the executive. Vision runs through the selected cloud model. The vision model relays a compact evidence report to the brain; text-only messages do not wait for a new vision pass. The API and body-control keys are encrypted with Android Keystore and stay on this phone. Opening Controls pauses the mind and stops the body; it resumes only after you return to the face.

Eyes

The chosen vision runtime receives fresh, downscaled camera frames on its own adaptive heartbeat and whenever current visual evidence is needed. It relays a compact evidence report to the chosen brain model. Ordinary text messages reuse recent perception for a faster response.

Autonomy is standing authority to use available senses, legs, gaze, research, and phone actions while pursuing tasks. These buttons are pause overrides, not approval prompts. Email tools still create a draft; they cannot silently send it.

Semantic cloud vision refreshes independently of conversation and pauses automatically when thermal protection requires rest.

Voice

Ears-open mode avoids repeatedly opening Android's microphone and its Samsung start/stop beep. Audio stays local until speech is detected; Android 13+ transcribes only that completed utterance with the system recognizer. Local pitch summaries can answer sustained humming with a short MIDI motif.

The microphone remains open locally and pauses while OwlBot speaks. Android 13+ uses the phone's system transcription without another API key.

Uses the speech engine installed and selected in Android settings. Online neural services are not embedded in the community build.

The last 240 conversation pairs plus reinforced long-term memories stay in this app's local storage. Relevant excerpts, durable memories, sensor data, and the current camera frame when Vision is on are sent to the selected mind provider each turn. Autonomy allows OwlBot to choose and pursue its own practical missions while this face remains active. When Autonomy is enabled, OwlBot may create tasks, choose goals, act through the body and phone, evaluate results, and continue without asking for approval each time. The controls can pause a capability. OwlBot may apply validated behavior adjustments within its tuning surface; executable APK code can never be rewritten or installed without owner review.
