## XRobots CAD renderings

`youcanbuilddog-9g-isometric.svg` and `youcanbuilddog-9g-top.svg` are documentation renderings generated from `CAD/dog02_9g.stp` in James Bruton/XRobots' [YouCanBuildDog repository](https://github.com/XRobots/YouCanBuildDog).

Source model copyright © 2026 James Bruton and released under the MIT License. The preserved license is at [`LICENSES/YouCanBuildDog-MIT.txt`](../../LICENSES/YouCanBuildDog-MIT.txt). These are CAD renderings, not photographs of the current OwlBot prototype.

The SVG files were generated with `tools/render_body_views.py`. The upstream STEP file is deliberately not duplicated in this repository.
